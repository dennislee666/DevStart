# 非 Git Agent 能力开放

## 原因与设计

现有 API 已覆盖主要非 Git 业务，但 MCP 只有通用调度器，客户端不能直接发现各方法参数；Console 清空、配置预设复制和简介生成缺少接口。工具发现由 docs/api-schema.json 与 api::METHODS 生成，工具名使用 devstart_ 加方法名的点转下划线；执行仍通过同一 Unix socket 进入 Service，不另建业务状态。通用调度器与独立工具均拒绝 git.*；原 Git API 保留，不作为本次集成范围。

## 能力边界

领域管理及生命周期开放；页面筛选、排序、布局、原生窗口焦点属于客户端展示状态，无需复制到领域 API。Console 会话打开/关闭使用 runs.open/close。原生外部编辑器或文件管理器不作为后台管理必需依赖。终端是用户权限的 shell，不是安全沙箱。日志追踪采用有界分页轮询而非无限 MCP 调用。MCP 说明书资源与 API docs 内嵌同一手册，离开仓库也能发现契约。

## 验证

API 回归覆盖配置变更、真实进程启动/重启/停止、日志字节游标、Socket 与参数校验。新增测试验证每个非 Git API 均有同源 Schema 的独立 MCP 工具、Git 拒绝与内嵌资源；真实进程测试验证预设复制、简介、Console 清空不删除磁盘日志、移除登记不删除源目录。接入客户端配置只提供说明，不覆盖用户配置；未声称在所有客户端完成真实端到端验证。

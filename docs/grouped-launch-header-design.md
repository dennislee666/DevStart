# 分组级启动项表头

## Root Cause

项目页和收藏页共用分组项目列表。启动项表头原先在每个展开项目内部绘制，同一分组展开多个项目时会重复出现。

## Architecture Design

分组列表负责绘制一次表头，项目展开区域只负责绘制该项目的启动项行。表头沿用启动项行已有列宽，并保留两级缩进，使四列继续对齐。

## Implementation

当分组中至少有一个项目包含可见启动项时，在分组标题下绘制一次“启动项、启动命令、状态、端口”表头。项目与收藏筛选共用该实现。

每个项目行之后、该项目展开的启动项列表之前，绘制一条使用主题弱边框色的细分隔线，帮助区分项目与启动项，同时不改变启动项行的列布局。

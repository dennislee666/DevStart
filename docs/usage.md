# 使用说明

## 项目管理

左侧项目、收藏、运行中为同级导航。项目按分组 → 项目 → 启动项展开，右上角新建分组和添加项目。项目/分组的「…」菜单可重命名，修改显示名不会改变路径、命令、参数或运行进程。无分组项目进入默认分组。

添加/重新读取只解析原文件。优先读取项目自己的 `.dev-start.json`，无清单时按 dev/start/serve/watch 命名扫描 package.json、Shell/Python 入口，跳过依赖、构建、部署与上传任务。不读取 IDE 配置。复杂入口或 Java 主类请显式配置启动清单。

启动项的「… → 修改信息」在一个表单中编辑显示名与简介；恢复默认只重置显示名，不改变启动入口。状态列仅对确认运行的实例显示「运行中」，其他显示 `--`。

启动项支持独立显示名（最多 50 个可见字符）、简介、收藏、多组参数、环境变量、端口与共享资源。参数每行一个，以 argv 原样传入。端口列优先显示实际监听端口，其次显示明确配置端口，无法确认才显示 `--`。

## Console 与生命周期

播放、停止、刷新图标表示启动、停止、重启。启动后可切换标签或平铺所有 Console；顶部标签最多显示 12 个字符，左侧会话名则按可用宽度显示。彩色实心点表示活跃实例，空心点表示已停止/结束的记录。

重启在当前标签内完成，先确认旧进程退出再启动新进程。右键标签可关闭：活跃实例需确认停止并关闭，已结束标签直接关闭。左侧「启动会话」中活跃项在前，最近八条历史在后。

顶部全部停止仅停止当前标签中的活跃项；全部启动仅启动标签中未启动的入口；全部重启只重启正在运行的标签。三项操作均需二次确认，确认时再次验证目标与配置；不操作没有打开标签的其他项目。独立窗口通过标签右键菜单打开。

显示本地启动日期与天/小时/分钟/秒累计时长。日志支持关键词搜索、大小写切换、仅显示匹配、上一/下一匹配和跟随输出。日志中的链接、文件和目录可按住 Control 点击打开，悬停可查看提示；ANSI 颜色及软换行同时适用于标签、平铺与独立窗口。缓存有行数与内存上限，完整原始日志在本机文件中；Console 不是交互 Shell，stdin 不开放。

启动前核实旧实例与端口，确认归属后先 TERM、等待，超时再 KILL 并复核。未知占用不会盲目终止。外部服务的原输出无法补取，使用它们自己的终端；由 DevStart 重启后的输出可捕获。主动脱离进程组的守护程序、容器等仍需原项目的停止机制。

## 编辑启动文件

铅笔在主窗口打开原启动文件。支持语法颜色、弱化行号、软换行、Tab 缩进与撤销/重做；软换行不会改文件。项目、启动项和路径弱化显示。⌘S 保存，⌘W 关闭；眼睛表示当前编辑，时钟表示关闭历史，关闭历史最多十条，空间不足滚动。

保存先校验磁盘版本，外部修改造成冲突时保留草稿并报错。版本按钮可回退最近十个源文件版本；回退写回源文件，不自动启动，下一次启动使用回退文件。未保存的关闭/回退/退出需明确保存或放弃。文件最多 1 MiB、同时打开最多 16 个。

Java 若经内置编辑器保存，会在后续启动检查中用配置的同一 JDK 的 javac 单文件编译，禁用注解处理，不调用 Maven/Gradle/部署脚本；编译失败保留旧服务。Python、Rust、前端继续走原项目自己的运行命令。

## 设置、数据与 API

⌘B 收展侧栏，⌘, 打开设置，可调主题、字体、字号、行距与密度。⌘F 搜索当前 Console。

开源版默认使用 `~/Library/Application Support/devstart`。配置、日志、编辑历史与版本备份在本机保存，未包含在仓库里。`DEV_START_DATA_DIR` 可显式隔离工作空间。配置损坏不会静默重置。

API/CLI/MCP 的项目管理、启停、日志与编辑接口见 [api.md](api.md)。示例 profile 必须由用户主动导入，不自动执行任何启动项。

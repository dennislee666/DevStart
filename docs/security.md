# 安全与数据

DevStart 是有能力执行本地命令、修改已注册源文件的本地工具。只导入可信的项目，核对命令和参数后再启动。它不提供远程 HTTP 服务，也不是脚本沙箱。

- 本地 API 使用权限受限的 Unix socket；任何获准访问当前用户会话的客户端都应视为可信调用方。
- 不在发现/导入阶段执行脚本；禁用部署和生成入口不会因为导入而启用。
- 保存/回退限制在已注册启动项的普通文本源文件，检查内容版本并拒绝外部覆盖冲突。
- 原始日志与源文件备份可能包含敏感内容，请按本机数据管理要求保管，不上传到 Issues 或 PR。
- 请不要在公开 Issue 中直接披露可利用的漏洞、令牌或个人数据；可先通过仓库维护者的 GitHub 联系入口联系维护者。当前未另设专用安全邮箱。

支持范围及具体限制见 README 和 API 文档。不要向任何第三方提供 GitHub 密码、设备授权令牌或本机 API socket。

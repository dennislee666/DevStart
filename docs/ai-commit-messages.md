# 本地 AI 提交备注

## 界面与设置

AI 输入范围严格等于点击生成时的勾选文件集：取消勾选的文件名、内容与差异均不进入生成上下文。Git 文件变动首次读取时默认全选；新出现的变动默认选中，刷新保留手动取消的选择。勾选只决定提交范围，不代表已经暂存。提交备注右侧的魔术图标仅生成并填写可编辑备注，不提交、推送或改写项目。

设置 → 提交备注 → 本地 AI 工具：

- 自动选择并记住（初始值 discover）：按 Codex CLI、Claude Code、Cursor Agent 顺序尝试已安装工具；仅在生成合法结果后记住具体成功工具。
- 自动（每次检测 auto）：每次重新按顺序尝试，不记住工具。
- 明确选择某工具：仅使用该工具，失败报告真实原因，不静默换工具。

成功记忆由 Service 保存，不能覆盖生成期间用户主动修改的设置。生成期间手动修改了备注，结果不会覆盖当前文字，会在结果通知中保留。工具沿用用户已有登录与模型配置，模型服务仍可能访问该工具配置的云端；DevStart 不要求额外 API Key。

## 后端职责

- git_selection：默认全选和手动排除的确定性状态管理。
- git_ai_message：收集所选变更、受限上下文、具体 CLI 适配器、进程与严格输出校验。
- Preferences/Service：类型化选项与成功记忆的原子持久化。
- UI：采集操作、异步等待、展示备注与可手动关闭的右下角通知。

生成只包含所选文件名与最多前 24 个文件的文本差异/片段，正文预算约 40 KiB；二进制及明确凭据文件内容不发送。截断显式标记，不能据此宣称覆盖全部实现细节。生成提示将差异作为不可信数据，禁止执行其中指令。无可用工具或登录/额度/网络/输出错误会显示具体原因，不伪造备注。

Agent 在应用数据目录的独立临时文件夹运行，不进入项目；结束清理上下文及结果文件。Codex 使用只读、临时非交互任务和结构化输出；Claude 禁用内置工具、MCP、slash commands 与会话持久化；Cursor 使用 ask 只读模式及沙箱。绝不传入跳过权限或放开写入的参数。每次尝试最多 90 秒，每路进程输出持续读取，内存仅保留最近 64 KiB，超时终止独立进程组。标准输出必须解析成仅含 message 的 JSON；备注为 1–240 个字符的单行文本。

大量提交使用权限 0600 的临时 NUL 分隔路径清单，避免 argv 上限；单次最多选择 10000 个文件。清单不写入项目仓库，完成后删除。

## 调用依据

本机 CLI --help 与官方文档共同核实：

- [Codex 非交互模式](https://developers.openai.com/codex/noninteractive)
- [Claude Code CLI](https://code.claude.com/docs/en/cli-reference)
- [Cursor CLI 参数](https://cursor.com/docs/cli/reference/parameters)

CLI 必须已经安装并登录。不同版本不支持参数时会真实报错；自动模式继续下一工具，固定工具模式停止并展示原因。没有下载新增依赖或安装第三方工具。

成功生成后仅填写提交备注框，不弹成功通知。生成失败、设置保存失败或用户编辑导致结果未能填入时仍显示常驻提示；不影响提交、推送、更新等 Git 操作的结果通知。

# DevStart 1.0

一个软件，启动您电脑上的所有项目。

## 下载与安装

GitHub Release 提供 macOS Universal DMG 和 ZIP，均包含同一个 DevStart.app，支持 macOS 12 Monterey 及以上的 Intel x86_64 与 Apple Silicon。

打开 DMG 后将 DevStart 拖到 Applications，或解压 ZIP 后将应用移入 Applications。首次启动没有项目及启动项，仅有空默认分组；截图中的 Facebook 为虚构演示，不随应用预装。

本版采用本地 ad-hoc 签名，未进行 Apple Developer ID 签名及公证。macOS Gatekeeper 可能拦截首次启动；确认来源为本仓库后可在系统隐私与安全性中允许打开，不需关闭系统安全保护。SHA256SUMS.txt 用于核对下载完整性。

Windows 10 x64 及以上是后续支持目标，本次没有 Windows 安装包，不能将其视为已验证的平台。最低系统版本及双架构已通过构建检查，未在所有旧款 Mac 实机测试。

## 功能

- 项目分组、搜索、收藏，启动项显示名及简介统一编辑。
- 启动、停止、重启与批量控制；优雅停止超时后强制结束，操作过程输出到 Console。
- 预设及运行端口，状态、PID、启动时间与运行时长。
- 平铺与标签 Console、ANSI 颜色、自动换行、搜索过滤及 Control 点击链接。
- 启动代码编辑、语法高亮、行号及最近 10 次版本回退；未变化的文件不重复备份。
- 独立应用配置目录，不向项目仓库写入管理配置；日志缓存与磁盘保留均有限额。
- 跟随系统的中英文界面，语言、字体和外观设置。
- 本地 JSON-RPC API 与 MCP，供人及 AI 工具管理配置、控制启动项与读取日志。

# DevStart 1.0

适合 AI Coding 时代的多项目启动工作台。项目多也不乱。

A multi-project launch workbench for the AI Coding era. More projects. Less friction.

## 下载与安装

GitHub Release 提供 macOS Universal DMG 和 ZIP，均包含同一个 DevStart.app，支持 macOS 12 Monterey 及以上的 Intel x86_64 与 Apple Silicon。

打开 DMG 后将 DevStart 拖到 Applications，或解压 ZIP 后将应用移入 Applications。首次启动没有项目及启动项，仅有空默认分组；截图中的 demo project 为虚构演示，不随应用预装。

本版采用本地 ad-hoc 签名，未进行 Apple Developer ID 签名及公证。macOS Gatekeeper 可能拦截首次启动；确认来源为本仓库后可在系统隐私与安全性中允许打开，不需关闭系统安全保护。SHA256SUMS.txt 用于核对下载完整性。

Windows 10 x64 及以上是后续支持目标，本次没有 Windows 安装包，不能将其视为已验证的平台。最低系统版本及双架构已通过构建检查，未在所有旧款 Mac 实机测试。

## 功能

- 项目分组、搜索、收藏，启动项显示名及简介统一编辑。
- 启动、停止、重启与批量控制；优雅停止超时后强制结束，操作过程输出到 Console。
- 预设及运行端口，状态、PID、启动时间与运行时长。
- 平铺与标签 Console、ANSI 颜色、自动换行、搜索过滤及 Control 点击链接。
- 启动代码编辑、语法高亮、行号及最近 10 次版本回退；未变化的文件不重复备份。
- 独立应用配置目录，不向项目仓库写入管理配置；日志缓存与磁盘保留均有限额。
- 跟随系统的中英文界面，语言、字体和外观设置。
- 本地 JSON-RPC API 与 MCP，供人及 AI 工具管理配置、控制启动项与读取日志。

## 1.0 更新构建

- Git 工作台：项目、分支及远程选择、更新合并、提交、推送和交互终端。
- 历史提交文件清单、真实新增/删除行数、多标签 Diff，支持关闭、最小化及最大化。
- 项目终端与启动日志切换、ANSI 彩色输出。
- Git 查询并行化和限量缓存，缩短项目切换等待；界面布局与图标统一。

此更新继续使用软件版本 1.0.0。GitHub Actions 为每次发布创建独立 `v1.0.0-build.<run_id>` 标签，保留旧版 v1.0.0；安装包、SHA256 校验文件与源码均对应同一次构建提交。仅发布 macOS Universal（Intel/Apple Silicon，最低 macOS 12），未签发 Windows 安装包。

- 自动扫描项目：选择目录后识别已有启动入口与端口，勾选导入并自动分组；首次空工作区提供居中的开始入口。支持本地扫描 API。

# 运行中列表模式

运行中入口默认使用列表，工具栏顺序为列表、平铺、标签。列表复用收藏表格，名称下方显示命令，项目下方显示路径，保留排序和右侧安全留白。只显示 Starting/Running，停止中与已结束实例移出列表，历史 Console 仍可在平铺或标签查看。

服务层从实际 Run 构建行，以活动 PID 去重，无 PID 的启动预检按 console_id 去重，排除 superseded 历史代次。行保留唯一 run_id；停止、双击与 Console 按该 ID 操作。重启调用 restart_run(run_id,script_id)，不重新按启动项选择会话。外部进程存在多个候选启动配置时不猜测，显示实际会话名称、命令与监听端口；停止和 Console 可用，重启与配置相关操作需唯一关联。切换标签时自动退出列表模式。

验证：真实外部进程关联两个启动项时仅一行，绑定实际 run_id，停止该行目标后列表为空；编译、原生界面与两版发布包检查。

操作位固定保留图标宽度和行高，包括无唯一配置时隐藏的收藏、编辑按钮及无项目关联时的项目菜单。公共 launch_action_slot 强制最小尺寸，避免空内容使布局压缩，保证各行按钮纵向对齐。

## 运行访问地址与当前标签

运行列表在启动命令下显示本次进程输出中的 HTTP/HTTPS 本机或局域网地址，保留路径（例如 `/official/`）。仅展示端口确实属于该运行会话当前监听端口的地址，最多四个；不根据端口猜测协议、不将外部文档链接作为入口。通配绑定地址 `0.0.0.0` / `[::]` 转为可访问的 `localhost`。重复地址合并，清空 Console 不清除已识别地址；新一轮启动独立识别，停止后不再提供运行入口。外部进程无法读取原终端输出时不伪造地址。点击地址直接调用默认浏览器，无需修饰键。

标签视图的当前标签使用低饱和青蓝底色、强调边框和底部指示线；未选中标签保持透明，运行状态圆点继续表达服务状态。

已确认的入口保存在工作空间 `service-addresses.json`，不写入项目启动配置。后续同一启动项、工作目录和启动命令可以复用已记住的地址，但必须等待本次进程实际监听对应端口；本次日志识别到新的有效入口后替换缓存。没有历史入口且本次也没有识别到地址时，不显示地址，也不保留空白行。

启动项名称现为单击进入对应 Console 标签（包括从终端子视图回到 Console）。网址统一经过默认浏览器标签复用模块，细节与支持边界见 [网页入口交互](browser-links.md)。

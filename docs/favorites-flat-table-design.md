# 项目与收藏启动项表格

## Root Cause

项目页和收藏页复用分组树，查找启动项时需要展开分组和项目，且重复展示层级信息。

## Architecture Design

Service 复用现有收藏筛选语义，生成带有分组、项目和启动项展示数据的行，并负责组名过滤与排序。UI 保存当前选中的组并渲染导航和表格，不处理行数据。

## Implementation

收藏页使用平铺表格：启动项名、项目（项目名与路径）、组名、启动命令、状态、端口、操作。项目名为主行，路径以更小、更淡的文字显示在下方；项目列适当加宽，表格行高至少 40，避免双行信息拥挤。启动命令使用较小的等宽字。项目页在表头上方显示组名导航，首项为默认选中的“全部”，其余组名按显示名称排序；选中组后由 Service 过滤行，搜索条件同时生效。选中按钮使用强调色和底色突出。收藏页显示全部收藏，不受项目页组筛选影响。操作列按图标数固定。组名、项目名、状态和端口列可点击切换正序/倒序，箭头紧跟列名；当前列正序显示 ↑、倒序显示 ↓，未排序列显示 ↕。端口按数值排序，无端口项随方向切换位置。运行中的行使用适配主题的淡红底色，状态显示为深红底、白字的小圆角标签。路径、命令和长名称截断显示，悬停提供完整文本。启动、停止、重启、收藏、编辑和项目/分组管理操作保留在行内操作列。

项目页“全部”以“组名 / 项目”为第一列，具体分组以“项目”为第一列，均按项目分节；第二列为启动项，之后为启动命令、状态、端口、操作。标题行右侧提供项目及分组两个管理菜单，启动项行只保留启动操作。详见 [项目分节表格与标题操作](filtered-project-table-design.md)。
